### Supertonic TTS 엔진 통합 — Phase 0 (Dependency Audit) 완료

**모델**: [Supertone/supertonic-3](https://huggingface.co/Supertone/supertonic-3) (ONNX, 99M params, 31개 언어, OpenRAIL-M)
**SDK**: PyPI `supertonic` 1.3.1 (`pip install supertonic`)
**핵심 사실**
- 44.1kHz 출력, 10개 프리셋 보이스 (F1–F5, M1–M5) `voice_styles/*.json`
- 아키텍처: text_encoder + duration_predictor + vector_estimator(flow matching, 8-step Euler) + vocoder
- 4개 ONNX 파일: `onnx/{text_encoder,duration_predictor,vector_estimator,vocoder}.onnx` + `tts.json` + `unicode_indexer.json`
- CPU 전용 (`CPUExecutionProvider`; GPU 미지원 upstream), torch 불필요
- 다운로드: `huggingface_hub.snapshot_download(repo_id, revision=SHA)` — **token 없음**
- 캐시: `~/.cache/supertonic3` 또는 `$SUPERTONIC_CACHE_DIR`
- 시드: `np.random.seed(seed)`로 완전 결정론적 · 재현 가능 (검증 완료)
- 언어: en ko ja ar bg cs da de el es et fi fr hi hr hu id it lt lv nl pl pt ro ru sk sl sv tr uk vi + `na` 폴백

**CPU 테스트 (throwaway venv, 아무 GPU 없음)**
- 로드 0.98s / 영어 7.14s audio in 1.97s (3.6x 실시간) / 한국어 4.81s in 2.2s
- seed=42 결정론 확인 True
- 로컬 staged 모델(`D:\TTS\supertonic-3\onnx`) + `voice_styles/`, `config.json` 만 추가로 다운로드해 검증

**PyInstaller 지시문 (Phase 5 예정)**
- `--hidden-import backend.backends.supertonic_backend` + `supertonic` (+ `supertonic.loader`, `supertonic.pipeline`, `supertonic.core`, `supertonic.config`, `supertonic.utils`)
- `--collect-binaries onnxruntime` (onnxruntime.dll / onnxruntime_providers_shared.dll — PyInstaller 자동 탐지 못함)
- `--copy-metadata` 없음 (supertonic 자체는 importlib.metadata 미사용; huggingface-hub 등은 기존 목록으로 커버)
