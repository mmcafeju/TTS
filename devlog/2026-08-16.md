### 발견/수정된 치명 버그 (5건)

1. **`configs/v2/40k.json` 부재** — v2는 32k/48k만 존재, 40k 학습 시 `make_config()` 실패. → `configs/v1/40k.json`을 복사해 생성 (sr=40000, hop=400, upsample=[10,10,2,2] 값 검증 완료)
2. **config 복사 경로 오류** — `configs/v2/{sample_rate}.json`(`40000.json`)을 찾았으나 엔진 명명은 `40k.json`. → `sr_label = f"{sample_rate // 1000}k"` 도입
3. **`-sr` 인자 오류** — `str(sample_rate)`("40000")를 넘겼으나 엔진 `models.py:555`는 `sr2sr[sr]` 딕셔너리 키("40k"/"48k") 사용. → `sr_label`("40k")로 전달
4. **`filelist.txt` 미생성** — `preprocess.py`는 파일리스트를 만들지 않지만 `train/utils.py:400`이 `hps.data.training_files = "%s/filelist.txt"`를 요구 → `_write_filelist()` 헬퍼 추가 (포맷: `<gt_wav>|<3_feature768>|<2a_f0>|<2b-f0nsf>|<spk_id>`)
   - 주의: hubert는 `{stem}.npy`, f0/f0nsf는 `{name}.npy`(확장자 포함)로 명명 불일치 → 각각 맞게 경로 생성
5. **`_finalize_model` 산출물 오류** — raw `G_*.pth`(학습 체크포인트, `{"model":...}`)를 복사했으나 추론은 `savee()` 산출물(`opt["weight"]`/`opt["config"]`/`opt["sr"]`) 필요 → `WEIGHTS_DIR/{model_id}.pth`(savee 출력) 우선, 없으면 G_*.pth 폴백. 인덱스도 `added_IVF*.index`/`INDICES_DIR/*{model_id}*.index` glob으로 수정
