### 5. ③ PyInstaller frozen 모드 설계 ✅
- **설계 원칙**: RVC 엔진(`backend/rvc_engine`)은 자체 venv(torch)+ffmpeg를 가진
  별도 서브프로세스 → **번들하지 않는다**. 런타임에 `<exe> 옆` 또는 `VOICEBOX_RVC_DIR`
  로 설치된 엔진 디렉터리를 찾는다.
- **구현 — `backend/config.py:get_rvc_engine_dir()`** 해석 순서:
  1. `VOICEBOX_RVC_DIR` env var (launcher가 미리 설정해야 함 — pipeline.py가
     import 시점에 경로를 캐시)
  2. frozen(`sys.frozen`): `Path(sys.executable).parent / "rvc_engine"` — exe와
     나란한 portable 레이아웃. `--onedir`(`dist/<name>/rvc_engine`)와 `--onefile` 모두 동작.
  3. `sys._MEIPASS` 하위 `rvc_engine` (미래 slim 번들 대비 fallback)
  4. 소스: `backend/rvc_engine` (개발)
- **구현 — `backend/voicebox-server.spec`**: VC 라우트/서비스 hiddenimports 추가
  (`backend.routes.vc`, `backend.services.vc[.gpu/.jobs/.pipeline]`) — frozen 바이너리가
  `/vc` API를 등록하고 엔진을 spawn할 수 있게. 상단에 설계 주석 기록.
- **검증**: 소스/환경변수/frozen(모의) 3분기 경로 해석 단위 확인 + pipeline import smoke
  + `test_cors.py` 20 passed.
