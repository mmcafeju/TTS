## §6. 오디오 출력 형식 기능 (feat) — 이번 세션 추가

### 목표
생성 창에 **출력 형식** 셀렉트(원본/방송용/CD용/MP3) + 규격 도움말 다이얼로그 표시.
TTS 저장 직전에 선택한 규격대로 변환: 방송용=48k/24bit/PCM/-24 LUFS/TP≤-1.0 dBTP,
CD용=44.1k/16bit/PCM, mp3=44.1k/192kbps CBR/-14 LUFS, 모두 듀얼 모노.

### 백엔드 (완료·검증)
- `backend/utils/audio_export.py` 신규: `FORMAT_SPECS`, `get_format_spec`, `resolve_ffmpeg`
  (VOICEBOX_FFMPEG → `config.get_rvc_engine_dir()/bin/ffmpeg(.exe)` → shutil.which),
  `_loudnorm_target`(듀얼 모노 보정), `_measure_loudness`(pass-1 JSON),
  `_loudnorm_filter`(pass-2 linear), `_encode`(aformat→loudnorm→pan=stereo|c0=c0|c1=c0
  →aresample, temp+atomic replace, `-f` 컨테이너 필수), `export_audio_file`.
- **듀얼 모노 보정**: EBU R128 미터는 L=R 듀얼 모노를 +3.01 LU 높게 측정 →
  loudnorm 타깃 = 규격 타깃 - 3.010299957. 검증: 방송용 I=-24.0/TP=-13.8, mp3 I=-14.0.
- `models.py`: `GenerationRequest.output_format` (pattern `^(broadcast|cd|mp3)$`).
- `services/versions.py`: `update_audio_path(version_id, audio_path, db)` (default면
  generation.audio_path 동기화).
- `services/generation.py`: `run_generation`·`_save_generate`·`_save_retry`·`_save_regenerate`에
  `output_format`; `_export_default_version` 헬퍼. mp3는 경로가 바뀌므로 원본 wav 삭제 +
  generation 행 repoint, broadcast/cd는 인플레이스 재인코딩.
- `routes/generations.py`: 요청 파라미터 전달.
- 검증: `test_audio_export.py` **4 passed** + `tests/manual_save_export_check.py`
  **15 checks passed** (retry/effects+방송/무효과+CD/무효과+MP3 경로 rename·행 동기화/default
  불변).

### 프론트 (완료·검증) — **브라우저 프론트 = `app`/`web` 공용, `app/src` 수정**
