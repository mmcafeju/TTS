# 2026-08-19 — 도움말/튜토리얼 미표시 문제 해결

## 상황
사용자가 "튜토리얼/도움말 기능이 안 보인다"고 보고 → 브라우저 실행해 확인.

## 원인
- 코드는 정상 커밋 상태(도움말/튜토리얼 시스템 구현 완료).
- **vite dev 서버(5173)가 꺼져 있어** 열려 있던 브라우저 탭들이
  `ERR_CONNECTION_REFUSED` 상태로 연결 오류 화면만 표시 중이었음.

## 조치
1. vite dev 서버 재기동: `web` workspace, 포트 5173 (Windows cmd, `web/vite.log`)
2. CDP(9222)로 상태 확인 → 연결 거부 확인
3. `scripts/help_browser_test.mjs` 전체 E2E 실행 → 통과
   (사이드바 아이콘, /help 14개 메뉴, 튜토리얼 1~5, 클로닝 규격 박스, 장문 힌트, 콘솔 에러 0)
4. 열려 있던 17개 페이지 탭 전부 reload → 정상 표시 확인
